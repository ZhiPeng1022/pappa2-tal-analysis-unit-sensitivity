# Genome Medicine supporting information v45

The v45 supporting information comprises six Excel workbooks and three supplementary figures. File numbering follows first citation in the main manuscript.

## Additional files

- Additional file 1. Analysis-unit calibration and frozen panel.
- Additional file 2. Single-cell neighborhood and within-donor analyses.
- Additional file 3. Unit-aware simulation benchmark.
- Additional file 4. PAPPA2 clinical and composition analyses.
- Additional file 5. External validation and regulatory context.
- Additional file 6. Graph, seed, and exact-state boundary analyses.
