# GitHub release checklist for v1.0.13

1. Review `release_manifest.csv` and `RELEASE_NOTES_v1.0.13.md`.
2. Run the unit tests in `software/unitaware`.
3. Commit the contents of this directory to the repository.
4. Create and push tag `v1.0.13`.
5. Create the GitHub release from `RELEASE_NOTES_v1.0.13.md`.
6. Attach `github_v1.0.13_ready.zip` to the GitHub release.
7. Confirm that Zenodo creates a new version under concept DOI 23196128.
8. Link unitaware v0.3.0 DOI 10.5281/zenodo.24441900 in the release metadata.

The unitaware v0.3.0 software DOI is already published. Repository commit, tag,
GitHub release, and the v1.0.13 Zenodo data archive are completed only after
their public URLs have been verified.

Recorded unitaware DOI: https://doi.org/10.5281/zenodo.24441900
