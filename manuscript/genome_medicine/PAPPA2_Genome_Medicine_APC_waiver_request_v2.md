## Scientific context

The manuscript develops and validates a unit-aware framework for single-cell
disease studies. It analyzes 106,851 human kidney TAL cells from 223 donors,
includes two non-KPMP support cohorts, and provides a prespecified 400-gene
panel with expression-matched random sets and an effect-aware conditional
null. The analysis code and derived data will be archived with a new
persistent DOI before formal submission and will be openly available.

The work addresses a general risk in genomic medicine: donor-level,
neighborhood-level, and within-donor analyses can support opposite conclusions
about the same cell state. A reusable framework can help other investigators
avoid treating these quantities as interchangeable.
